Мой проект – Тетрис с ИИ. Суть проекта – это соревнование против ИИ в игре тетрис. При запуске приложения у игрока выходит «Главное меню», в котором он может ввести ник, выбрать метод управления (стрелки или wasd), а также посмотреть таблицу лидеров, в которую записываются результаты игроков. После ввода ника, пользователю предлагается выбрать уровень сложности ИИ и начать игру.

Основной файл – main5.py

Вспомогательные файлы, учувствовавшие в процессе обучении – test_dagger.py, dagger_train.py, ai_model.py. (их запускать не надо).

Обучение реализовано на нейросети MLP с помощью метода dagger (аналог обучения с учителем) – был сделан эвристический бот, на ошибках которого, училась нейросеть.

Для запуска необходимо: файлы - main5.py, ai_model.py и dagger_v4.pth положить в одну директорию. И запустить main5.py.

Необходимый библиотеки для запууска: 

pip install pygame или pygame-ce

pip install numpy

pip install torch
